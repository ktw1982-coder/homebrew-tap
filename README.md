# Homebrew Tap for ktw1982-coder

Official Homebrew Tap repository for macOS applications created by `ktw1982-coder`.

## Installation

To install **Antigravity Monitor** via Homebrew Cask:

```bash
brew install --cask ktw1982-coder/tap/antigravity-monitor
```

Or tap first:

```bash
brew tap ktw1982-coder/tap
brew install --cask antigravity-monitor
```
